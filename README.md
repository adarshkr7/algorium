# CFDual

CFDual is a real-time, competitive programming platform designed for 1v1 duals using Codeforces problems. Built with Next.js, Prisma, and Supabase, it allows users to create customized rooms, challenge opponents in Classic or Blitz game modes, and track live contest standings as submissions are automatically evaluated. Whether you are hosting a supervised match or facing off directly with a friend, CFDual brings an interactive, fast-paced environment to algorithmic problem solving.
